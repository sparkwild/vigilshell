# VigilShell

## 开发

开发环境与依赖版本见[技术栈](docs/TECH_STACK.md)。

```sh
nvm use
npx --yes npm@11.19.1 ci
npm run dev:app
```

首次启动准备[签名身份](docs/TECH_STACK.md#签名准备)，日常开发复用现有 VigilShell Dev。
