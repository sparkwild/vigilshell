# Security policy / 安全政策

Report security vulnerabilities through [GitHub's private vulnerability reporting form](https://github.com/sparkwild/vigilshell/security/advisories/new). Include the affected VigilShell version or commit, macOS version, the impact, and steps to reproduce with test data. Replace real server details, SSH credentials, MCP tokens, and signing material with placeholders before attaching logs or screenshots. Keep vulnerability details in the private report while coordinating disclosure.

Use [GitHub Issues](https://github.com/sparkwild/vigilshell/issues) for ordinary bugs and feature requests.

发现安全漏洞时，请通过 [GitHub 私密漏洞报告表单](https://github.com/sparkwild/vigilshell/security/advisories/new) 提交。请注明受影响的 VigilShell 版本或提交、macOS 版本、影响，以及使用测试数据复现的步骤。附上日志或截图前，请将真实服务器信息、SSH 凭据、MCP 令牌和签名材料替换为占位内容。在协商披露期间，请在私密报告内交流漏洞细节。

普通缺陷和功能建议可以提交到 [GitHub Issues](https://github.com/sparkwild/vigilshell/issues)。
