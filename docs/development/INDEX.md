# Development Documentation

This category owns the durable rules for implementing, validating, releasing,
reviewing, and maintaining VigilShell.

## Belongs Here

- Code organization, typed contracts, testing, fixtures, release, review, and documentation-maintenance standards.

## Does Not Belong Here

- One-off implementation slices, task status, acceptance output, or open investigations.

- [ENGINEERING_STANDARDS.md](ENGINEERING_STANDARDS.md) — implementation, test, UI-validation, and review rules.
- [RELEASE_DISTRIBUTION.md](RELEASE_DISTRIBUTION.md) — artifact, signing, update, and publication standards.
- [DOCUMENTATION_STANDARDS.md](DOCUMENTATION_STANDARDS.md) — durable-document ownership and maintenance rules.
