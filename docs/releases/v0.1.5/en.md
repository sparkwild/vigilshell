## Features

- **Intel Mac support:** VigilShell now offers a dedicated installer for Intel Macs, alongside the existing Apple Silicon version.
- **Architecture-aware updates:** In-app updates match the architecture of the installed app. Intel builds running under Rosetta continue to receive Intel updates.

## Upgrade Notes

- For a manual installation, download the Apple Silicon or Intel installer that matches your Mac.
- Versions 0.1.3 and later can update in the app. For earlier published versions, download the DMG and replace the app manually.
