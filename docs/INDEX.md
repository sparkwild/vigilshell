# VigilShell Documentation Index

The root [README](../README.md) is the public project entrypoint, and the root
[AGENTS.md](../AGENTS.md) is the coding-Agent bootstrap. `docs/` owns the durable
detail behind both surfaces. Task plans, progress snapshots, research, review
evidence, and handoffs remain working material outside this tree.

Use this index to select the category and documents relevant to the current
task; loading every document is not a default requirement. The current five
categories are an established navigation structure, not a template that future
documents must expand. Add a document only when it has confirmed durable content
and a distinct owner.
