# Features Documentation

This category owns durable product behavior, workflows, capability boundaries,
and user-visible interaction rules.

## Belongs Here

- Human and Agent capabilities, functional modules, workflows, and feature limits.

## Does Not Belong Here

- Runtime topology, dependency selections, implementation status, or coding rules.
